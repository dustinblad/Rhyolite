Hybrid Storage Engine: Plain Markdown + SQLite Sidecar

Rhyolite preserves plain .md files on disk as the canonical source of truth while pairing them with a lock-free in-memory AST and [[Avalonia Rendering Pipeline]]. Keystrokes never block on disk I/O.

⚡ [!IMPORTANT] Zero-Latency Typing Pipeline

Edits mutate the in-memory rope buffer in < 0.05 ms. A background channel debounces disk writes (400 ms) and incrementally updates only the changed note's edges in .rhyolite/cache.db.

Question

Why does Rhyolite pair plain .md files with a SQLite WAL sidecar cache instead of storing note bodies inside SQLite?

Answer

1. Zero Lock-In: Plain .md files remain directly editable by VS Code, Git, iCloud, and scripts.
2. < 1 ms Typing Latency: In-memory AST updates only the edited file's delta.
3. < 50 ms Cold Startup: SQLite WAL caches pre-parsed links, frontmatter, and FTS5 tokens across 10,000+ notes.
